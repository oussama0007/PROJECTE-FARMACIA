


# FARMA+ — Botiga Online de Farmàcia

## Descripció del projecte
FARMA+ és una aplicació web de venda de productes de farmàcia desenvolupada amb PHP, HTML, CSS i Bootstrap.

## Funcionalitats
- Registre, inici de sessió i tancament de sessió.
- Gestió del perfil d'usuari.
- Visualització i cerca de productes.
- Carret de compra amb gestió de quantitats.
- Realització de comandes i historial de compres.
- Generació de factures en PDF.
- Panell d'administració per gestionar productes, usuaris i comandes.
- Canvi d'idioma entre català i anglès.

## Tecnologies utilitzades
- PHP
- HTML i CSS
- Bootstrap
- Docker
- Sessions PHP
- Dompdf per generar factures PDF

## Instal·lació
1. Clonar el repositori.
2. Obrir el projecte amb Visual Studio Code.
3. Tenir Docker Desktop instal·lat i en funcionament.
4. Executar la comanda:

```bash
docker compose up -d
```

5. Obrir el navegador i accedir a:

`http://localhost:8089`

## Emmagatzematge de dades
Les dades dels usuaris, productes, carrets i comandes es gestionen mitjançant arrays i sessions PHP, sense base de dades externa.
